### Core Project Odin Concepts
Project Odin is an ambitious exploration of an infinite mathematical universe based on arithmetic coding. The ChartGenerator serves as the primary navigator, allowing traversal through coordinate space using:
- Sublight travel for small adjustments
- Hyperspace jumps for encoding random byte sequences
- fold_r mechanism to maintain numerical stability by adjusting the reference axis R when drift becomes too large
- Bookmarks and galactic mapping for persistent navigation

The core insight is that every possible byte sequence exists as a coordinate (V, R, direction) in this Burris Numerical System. The primary challenge is not generation, but efficient discovery of structured, meaningful data amid infinite noise.

### Key Technical Components
1. **HandMath**: Arbitrary-precision integer handling using limb arrays for large coordinate calculations.
2. **write_disk_image**: Critical function that decodes a coordinate into raw bytes of specified length.
3. **LatticeFS**: Virtual filesystem layer with optional encryption.
4. **Harvesting Strategy**: Generate coordinates → decode → file carving (magic bytes, entropy analysis) → validation → ingestion into Muninn.

### Muninn's Role
Muninn operates completely decoupled from the ChartGenerator core. It:
- Monitors the `/odin_staging/` directory
- Processes carved files (text, PDFs, images, etc.)
- Creates structured knowledge profiles with summaries, entities, and metadata
- Supports retrieval-augmented conversation
- Maintains long-term memory of all discoveries from the Informational Universe
